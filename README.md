# tsotne.blog

Source for my personal site at **[tsotne.blog](https://tsotne.blog)** — built on the [Chirpy][chirpy] Jekyll theme and deployed via GitHub Pages.

It's where I write about **AI engineering, security, and backend architecture** — mostly things I learned the hard way and wish someone had told me first.

- Live site: <https://tsotne.blog>
- About me: <https://tsotne.blog/about/>
- Projects: <https://tsotne.blog/projects/>
- Contact: [cotne.ok@gmail.com](mailto:cotne.ok@gmail.com) · [LinkedIn](https://www.linkedin.com/in/tsotne-okrostsvaridze-ab1b5958/)

## Local development

```bash
bundle install
bundle exec jekyll serve
```

The site builds and deploys automatically via `.github/workflows/pages-deploy.yml` on every push to `main`.
